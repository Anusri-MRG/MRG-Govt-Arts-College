# Implement Client Script & UI Policy (Incident)

## Project Overview

This project demonstrates the implementation of Client Scripts and UI Policies in ServiceNow using the Incident table.

## Objective

To implement dynamic field behavior, automatic field updates, save validation, and restrictions on list editing.

## Technologies Used

- ServiceNow
- Client Scripts
- UI Policies
- Incident Management
- Update Sets

## Features Implemented

- High Impact Control UI Policy
- Assignment Group mandatory for high impact incidents
- Urgency made read-only for high impact incidents
- Automatic Urgency update using onChange Client Script
- Assigned To validation using onSubmit Client Script
- State list-edit restriction using onCellEdit Client Script
